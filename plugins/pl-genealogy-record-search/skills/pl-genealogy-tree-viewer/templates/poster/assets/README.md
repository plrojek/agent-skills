# Poster illustrations

Three tree illustrations for the poster configurator, 5016 × 2823 px JPG (quality 94, 4:4:4), with
small thumbnails for the picker. Posters and their PDFs always use the full illustration. At 841 mm
wide an illustration prints at about 151 dpi; a larger paper size does not raise that.

- `background1.jpg` — watercolour ("Akwarela")
- `background2.jpg` — botanical tree ("Botaniczne")
- `background3.jpg` — golden oak ("Złoty dąb")
